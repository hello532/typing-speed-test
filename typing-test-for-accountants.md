# Typing Test for Accountants

Source: https://typing.rerivo.com/typing-test-for-accountants.html

Accountants do not need prose speed. They need numeric accuracy at pace: 10-key entry, decimals in the right place, and the ability to type a figure once and have it be right.

A ledger entry is a date, an account code, a description and an amount. Three of those four are numeric or alphanumeric, and the amount has a decimal point in a position that matters more than any word you will type all day.

Firms rarely quote a words-per-minute figure in accounting adverts because prose speed is not the constraint. If they test at all, it is a numeric or 10-key exercise, or an Excel-based work sample.

Task | Target | Why
10-key numeric entry | 8,000-12,000 KPH | The band employers quote for numeric data entry
Accuracy on amounts | 99%+ | A transposed digit is a reconciliation problem
Alphanumeric codes | 97-98% | Account and tax codes mix letters and digits
Prose notes | 40-50 WPM | Enough for memos and client correspondence

In practice the accuracy column decides whether you are useful. A 12,000 KPH entry rate with 96% accuracy creates more work than it saves, because every error has to be found later.

Learn the keypad as a separate instrument: 4-5-6 on the home row, index on 4, middle on 5, ring on 6, thumb on 0. Type without looking, entering a figure and pressing Enter after each, which is how accounting software behaves.

Then add the parts that break in real work: negative signs, decimal points, and the Tab key between fields. A drill that only types clean integers trains a skill you will never use.

Use the 10-key typing test for keypad speed, the Numbers mode on this page for mixed numeric content, and the Excel formula practice page for spreadsheet syntax. Then measure prose separately with the WPM test if a posting asks for it.

Keep the three numbers distinct on a CV. "12,000 KPH 10-key, 99.2% accuracy; 48 WPM prose" tells an accounting manager far more than a single WPM figure.

## Frequently asked questions

### What typing speed do accountants need?

Postings rarely quote one. Numeric entry at 8,000-12,000 keystrokes per hour with 99% accuracy on amounts matters more than prose speed, which is usually fine at 40-50 WPM.

### Is 10-key speed tested for accounting jobs?

Sometimes, especially for accounts payable, payroll and bookkeeping roles. Larger firms more often use an Excel work sample, which tests the same accuracy under realistic conditions.

### How fast is 10,000 keystrokes per hour?

About 33 words per minute equivalent, or 167 characters per minute. On a numeric keypad that is a comfortable working pace rather than a sprint.

### Why does accuracy matter more than speed here?

A transposed digit in an amount becomes a reconciliation break, which takes longer to find and fix than the entry saved. Accounting work is judged on the ledger balancing, not on entry rate.

### Should I practise on the number row or the keypad?

The keypad, for amounts. Use the number row only for alphanumeric strings such as account codes where your hand is already on the main keyboard.
