  • 收录不是主缺口：URL Inspection API 权威口径 45/49 已编入；GSC 页面上的「13 未编入」是历史累计口径（含已被替代 URL 的残留）。真实未抓取只有 4 页：

5. 已落地的增长杠杆

  • 收录侧：3 个高曝光页（212 / 206 / 102 曝光）加内链指向 4 个未抓取页；4 页各补独特深度小节（+73 / +76 / +70 / +92 词），全过 687 段语料查重。

  • 推动侧：4 页逐个「请求编入索引」（均确认入优先抓取队列）；sitemap 重提并已被重新下载；IndexNow 49 URL 全量重提成功。
  • 度量侧：gsc.py growth 一键算增幅，retro.py 复盘含搜索表现段，基线版本化可 diff。

6. 为什么现在还看不到 +200%

  • 数据延迟：GSC 表现数据约 1 天延迟，收尾时窗口仍覆盖优化上线之前。
  • 收录发酵：请求编入索引只是入队，重新抓取与重新评估排名需数天至数周。
  • 排名传导：TDK 与内容改动要等下一次抓取生效，CTR 变化又滞后于排名变化。
  • 因此本轮不宣称涨幅；正确读法是「基线已固定 + 杠杆已上膛 + 度量已就位」。
