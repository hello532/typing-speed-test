# Keyboard Tester

Source: https://typing.rerivo.com/keyboard-tester.html

Press any key. The panel shows its name, code, keyCode and the finger that should reach it &mdash; the fastest way to find a dead key or a key mapped to the wrong place.

A keyboard tester shows what your computer receives when you press a key: the key value, the physical code (its position on the board), the legacy keyCode, and the finger that a touch typist would use to reach it.

Because the panel listens at the document level rather than inside a text box, it reports keys that a typing test would silently ignore: modifiers, function keys, arrow keys and anything a keyboard layout has moved.

After a spill, a drop or a deep clean. A key that types nothing in a text field can still be sending a code, and a key that sends the wrong code looks like a typing mistake. The panel separates those two cases.

After switching layout. On Dvorak or Colemak the letters move but the physical code stays put, so a tester is the quickest way to confirm which board key lands on which letter. See keyboard layouts for the layouts this site supports.

Before blaming your speed. If one key misses intermittently, no amount of practice fixes it. Test first, then work on typing practice.

code is the physical position, for example KeyF or Semicolon, and it does not change when you switch layout. key is the character your layout produces at that position, so it does change.

If a key shows no change at all, the switch or the connection is the problem. If it shows a different key than the one printed on the cap, the layout or the mapping is the problem. The finger label tells you which one should have reached it.

## Keyboard tester FAQ

### Does the keyboard tester work with any keyboard?

Yes. It reads the key events your operating system delivers, so it works with laptop keyboards, USB and Bluetooth boards, and any layout you have active.

### Why does a key show a different letter than the one printed on it?

Your active layout differs from the keyboard's physical layout, or the key is remapped. Compare the code (physical position) with the key (the character produced) to see which.

### Can it detect a dead key?

Yes. A dead key produces no change in the panel at all. If the key produces a code but the character is wrong, the hardware works and the mapping is the problem.

### Does it record what I type?

No. Keys are shown in your browser only, nothing is stored, sent or logged, and the list is cleared when you reload the page.

Yes, free with no sign up and no ads inside the tool area.
