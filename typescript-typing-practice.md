# TypeScript Typing Practice

Source: https://typing.rerivo.com/typescript-typing-practice.html

TypeScript adds a second layer of punctuation to JavaScript: angle brackets, colons, question marks and arrows in every signature. This drill types 36 real lines from application code, not toy examples.

## The symbols that cost you time

Angle brackets for generics, typed with Shift plus comma and Shift plus full stop - two reaches that pull both hands off the home row.
Colons and question marks in type annotations and optional properties, frequently adjacent.
Arrow operators in callbacks, which need the hyphen and the greater-than key in sequence.
Braces and parentheses in destructuring and object literals, often nested three deep.

A JavaScript typist at 65 WPM typically measures 50-58 WPM on the same content once types are added. That is not a regression in skill; it is more symbol work per line.

## What is in the pool

Thirty-six lines taken from ordinary application code: an interface with optional fields, a discriminated union result type, a typed reducer, a generic type guard, an error class with a constructor parameter property, a debounce hook, a fetch with an abort signal, and a schema `.safeParse` branch.

They are deliberately not one-liners from tutorials. Real files mix declarations, expressions and early returns, and switching between those shapes is what makes editor typing feel different from typing a passage.

## Practising for real work

Type the lines as written, including semicolons and trailing commas. Autocomplete does not type for you during the drill, which is the point: you are rebuilding the muscle memory that autocomplete usually hides.

Then run one round with the on-screen keyboard visible and watch which key your eye goes to before the miss. It is usually the bracket cluster on the right, and it is fixable in a week of two-minute drills.

## Frequently asked questions

### Is TypeScript typing slower than JavaScript?

Yes, typically 10-20% slower at the same accuracy, because types add angle brackets, colons, question marks and arrow operators that JavaScript does not require.

### What speed should a developer type at?

Most developers sit above 60 WPM on prose and 45-55 WPM on code. No employer screens for it, but below 40 WPM the keyboard starts to limit how much code and documentation you produce.

### Does autocomplete make this pointless?

No. Autocomplete hides the symbol reaches, so they stay weak. Typing full lines rebuilds them, which is what you need when you write something autocomplete does not know.

### Is this real TypeScript?

Yes, 36 lines of ordinary application TypeScript: interfaces, unions, generics, hooks, async/await, error classes and schema validation branches.

### How long until I see improvement?

Two weeks of five-minute daily drills usually shows 5-8 WPM on this content, mostly from the bracket cluster ceasing to need a visual check.
