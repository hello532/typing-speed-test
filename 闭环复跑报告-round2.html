② 竞品级功能增强 静态可实现

改动集中在 src/engine.js / result.html / style.css / ui.js，经单一模板全站生效。
  • 键位热力图（keybr / TypingMaster）：成绩出炉后按本局keyErrors（错键次数）+keyTime（平均击键耗时）给屏幕键盘上色，绿→黄→橙→红四档（.heat-1..4），弱键一眼可见；reset() 清色，移动端随键盘隐藏。
  • 成绩分级 + 百分位（TypingMaster / Ratatype 档位）：结果页新增 #tierLine，按 WPM 落入 Beginner / Developing / Average / Above average / Fast / Elite，并给出「约前 10% / 前 1%」等标注；档位与 average-typing-speed.html 基准表同源，五语 i18n。
  • 分级证书（Ratatype 阶梯）：可打印证书新增奖级徽章 —— ≥70wpm&≥99% 💎 Platinum、≥50&≥97% 🥇 Gold、≥40&≥95% 🥈 Silver，否则 ✅ Completion。
  • Colemak 布局（keybr / TypingMaster）：引擎新增 COLEMAK_ROWS / COLEMAK_FINGER（26 字母全覆盖，指法按物理 QWERTY 位映射），工具条升级为 QWERTY / Dvorak / Colemak 三路切换，buildKbd 按最终布局重绘（含空格键，顺带修掉旧 dvorak 重绘丢空格的缺陷）。
