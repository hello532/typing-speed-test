**关键事实：加载器装了但没有广告单元，等于一分钱都不会有。** 必须走下面两条路之一。

## 二、路线 A：自动广告（零代码，推荐先用）

1. AdSense 后台 → **广告** → **按网站** → 选 `typing.rerivo.com` → 开启**自动广告**
2. 在「广告格式」里关掉**锚定广告**和**插页式广告**（对打字工具站是灾难，且插页式容易被判干扰性）
3. 保留「页内广告」，并在「排除」里把测试区所在的容器排除掉

自动广告不需要改代码，现有的加载器脚本足够了。

## 三、路线 B：手动广告位（可控，需要 2 个广告单元 ID）

1. AdSense 后台 → **广告** → **按广告单元** → 新建 2 个 **展示广告** 单元：
   - `typing-body`（页内，自适应）
   - `typing-footer`（页内，自适应）
2. 复制每个单元的 `data-ad-slot` 数字（10 位）
3. 填进 `src/pages.json`：

```json
"ads": {
  "client": "ca-pub-1401237223139327",
  "slotTop": "1234567890",
  "slotBottom": "0987654321"
}
```

4. `python3 build.py && python3 verify.py && git commit -am "ads: 填入手动广告位" && git push`

位置纪律（已固化在模板里，别改）：
- `{{AD_TOP}}` 在**正文之后、FAQ 之前**
- `{{AD_BOTTOM}}` 在**页脚之前**
- 打字区、结果区、TLDR 摘要区**永不出现广告**

## 四、CMP（同意管理平台）——没有它，欧洲流量等于白跑

AdSense 政策要求对 EEA / 英国 / 瑞士 的访客，在投放个性化广告前取得同意，且必须使用 Google 认证的 CMP。

1. AdSense 后台 → **隐私权和消息** → **GDPR 消息** → 创建
2. 站点语言选英语，样式用默认即可
3. 发布后，欧洲访客会看到同意横幅；拒绝则投放非个性化广告

未启用时的后果：EEA/UK/CH 的广告请求会被拒，那部分流量零收入（不是违规封号，但白跑）。

另外建议同时开 **CCPA 消息**（美国加州），AdSense 后台同一个入口。

## 五、收款与银行账户（AdSense 账号侧，与本站代码无关）

| 门槛 | USD 账户 | 动作 |
|---|---|---|
| 提交税务信息 | $0 | 收款 → 管理税务信息 → W-8BEN |
| 身份验证 | $0 | 收款 → 验证身份（上传证件）**2026 起强制，不做不能展示广告** |
| 地址验证（PIN 平邮） | $10 | 余额到 $10 后 Google 寄 PIN |
| 选择收款方式（填银行） | $10 | 收款 → 收款信息 → 管理支付方式 → 添加付款方式 → 电汇 |
| 起付 | $100 | 余额过 $100 才真正打款 |

中国大陆电汇必填：账户所有人姓名（拼音，与开户名一致）、银行名称、SWIFT-BIC、账号（纯数字）。全部用拉丁字符。

## 六、收入现实检查（别自欺）

- 2026-08-01→11-10 共 90 天：**曝光 6,733，点击 98**
- 2026-10-28 起曝光归零（站点被踢出索引，见 `SEO-INCIDENT-2026-11-11.md`）
- 假设恢复到历史峰值并拿到 $3 RPM：`6,733 imp/90d ÷ 1000 × $3 ≈ $0.20/90 天`
- 要攒到 $10，按历史最优流量需要 **约 12 年**；按起付 $100 更是不可能

**结论：这条路的天花板不在 AdSense 配置上，在流量上。** 想真正拿到钱，必须先解决索引问题，再把流量提高两个数量级（或换更高单价的主题）。
