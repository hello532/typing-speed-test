# Custom Typing Test

Source: https://typing.rerivo.com/custom-typing-test.html

A fully customizable typing test: pick your duration from 15 seconds to 10 minutes, switch between sentences, quotes, numbers and words, set the language, theme and line width, then type and get instant WPM. Everything is configurable, nothing to sign up for.

Interview rehearsal - paste a passage in the style of the employer's test (legal clause, medical note, code snippet) and practise at the same length.
Weak-key drilling - paste the words you keep missing, twenty times each, and run a minute on them.
Domain vocabulary - drug names, part numbers, legal defined terms. Typing your own vocabulary beats typing random sentences.
Classroom use - paste a passage from the week's reading so practice reinforces content rather than competing with it.

The custom text is stored in your browser for the session; nothing is uploaded, which is what makes the classroom use case workable.

Paste plain text. Formatting, smart quotes and non-breaking spaces can all produce characters your keyboard cannot type, which turns a practice round into a hunt for a Unicode symbol.

Keep it between 100 and 400 words. Shorter and the round repeats, which makes memorisation inflate your score; longer and you will never finish a five-minute round.

Setting | Use it when
Duration | Match the real test length; use 60 seconds for warm-ups only
Text mode | Sentences for prose, Numbers for codes and amounts
Layout | QWERTY by default; change it if you actually type on Dvorak or Colemak
Theme and width | Comfort only - they do not change the score

A custom test cannot tell you whether the passage is representative. If you paste easy words, you will score higher than on an employer's test and believe you are ready.

Use it for targeted practice, and the standard tests for benchmarking. For the benchmark itself, see the one-minute test or the five-minute test.

## Custom typing test FAQ

### What is a custom typing test?

A test where you supply the text - your own vocabulary, a sample passage or an interview-style document - and the engine measures speed and accuracy on it.

### How much text should I paste?

100-400 words. Under 100 the round repeats and memorisation inflates the score; over 400 you will not finish a five-minute round.

### Is my pasted text uploaded?

No. It stays in the browser for the session; there is no server-side storage and no account.

### Can I practise code in a custom test?

Yes, though the dedicated code pages (Python, JavaScript, TypeScript, Rust, SQL) have symbol-dense pools written for that purpose.

### Why does my custom score differ from the standard tests?

Because the text differs. A custom passage with easy words or no punctuation will read higher than a standard sentence test - use the standard tests for benchmarks.
